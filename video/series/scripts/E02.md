# Episode 2 — Matrices, vectors, and eigenvalues from scratch

Audience: someone who has never seen a matrix. Every operation is done by hand on small
examples before the general statement.

## E02S01 — Vectors: lists of numbers

1. Last episode ended with a promise: turn a graph into a table of numbers. Before the table, we need the lists. A vector, for us, is just an ordered list of numbers, one number per vertex of the graph. For the four-cycle, with vertices zero to three, a vector has four entries. Here is one: one, two, zero, minus one. We write it as a column and call it x, and we write x zero, x one, x two, x three for its entries.

2. Think of a vector as assigning a number to each vertex. Here is the four-cycle with the number one written at vertex zero, two at vertex one, zero at vertex two, and minus one at vertex three. The picture and the column are the same information.

3. Two things you can do with vectors. Add them entry by entry: one, two, zero, minus one, plus one, one, one, one, gives two, three, one, zero. And multiply by a single number, entry by entry: three times one, two, zero, minus one is three, six, zero, minus three. Those two operations are all we need.

## E02S02 — The adjacency matrix

4. Now the table. Number the vertices zero to N minus one. The adjacency matrix A has N rows and N columns. In row x and column y, write a one if vertices x and y are joined by an edge, and a zero if they are not. The diagonal, where the row and column are the same vertex, is zero, because a vertex is not joined to itself.

5. For the four-cycle: vertex zero is joined to one and three. So row zero reads zero, one, zero, one. Vertex one is joined to zero and two: row one reads one, zero, one, zero. Row two: zero, one, zero, one. Row three: one, zero, one, zero. Four rows, four columns, eight ones. Each one is half an edge: the edge zero to one appears once in row zero and once in row one. So the number of ones is twice the number of edges.

6. Notice that the matrix is symmetric: the entry in row x, column y equals the entry in row y, column x, because an edge joins both ends equally. Flip the table across its diagonal and it is unchanged. Symmetric matrices have special properties, and the first one is coming up shortly.

7. Also notice: the number of ones in a row is the degree of that vertex. For a cubic graph, every row has exactly three ones. Here is the adjacency matrix of the Petersen graph, ten by ten. Row zero: vertex u zero is joined to u one, u four, and v zero. Three ones in that row. Every row has three ones.

## E02S03 — Multiplying a matrix by a vector

8. Here is the one operation we need. A matrix A times a vector x gives a new vector, written A x. The rule: the entry of A x at position i is obtained by taking row i of A, multiplying it entry by entry against x, and adding up. Row i, dotted with x.

9. Do it for the four-cycle with x equal to one, two, zero, minus one. Row zero is zero, one, zero, one. Multiply against x: zero times one, plus one times two, plus zero times zero, plus one times minus one. That is two minus one, which is one. So the first entry of A x is one.

10. Row one is one, zero, one, zero. Against x: one times one, plus zero, plus one times zero, plus zero. That is one. Row two: zero, one, zero, one, against x: two minus one is one. Row three: one, zero, one, zero: one plus zero is one. So A x equals one, one, one, one.

11. Now look at what the rule actually did. Row i has a one exactly at the neighbours of vertex i. So the entry of A x at vertex i is the sum of x over the neighbours of i. That is the whole meaning of the adjacency matrix. Multiplying by A replaces each vertex's number by the sum of its neighbours' numbers. Check it on vertex zero: its neighbours are one and three, carrying two and minus one, sum one. Correct.

12. Keep this picture: A x equals, at each vertex, the sum over the neighbours. In a cubic graph, each vertex adds up its three neighbours. Every statement about adjacency matrices in this series can be translated back into that sentence.

## E02S04 — Eigenvectors: vectors the matrix only stretches

13. Usually A x points in a completely different direction from x, as in the example: one, two, zero, minus one became one, one, one, one. But some special vectors come back as a multiple of themselves. Try x equal to one, one, one, one on the four-cycle. Each vertex sums its two neighbours, each carrying one: the sum is two. So A x is two, two, two, two, which is two times x.

14. A vector x, not all zeros, with A x equal to some number lambda times x is called an eigenvector of A, and the number lambda is called its eigenvalue. The matrix does not rotate or scramble an eigenvector. It only stretches it, by the factor lambda. For the all-ones vector on the four-cycle, lambda is two.

15. Try x equal to one, minus one, one, minus one. Vertex zero's neighbours, one and three, carry minus one and minus one: sum minus two. Vertex one's neighbours carry one and one: sum two. So A x is minus two, two, minus two, two, which is minus two times x. Eigenvalue minus two.

16. Try x equal to one, zero, minus one, zero. Vertex zero's neighbours carry zero and zero: sum zero. Vertex one's neighbours, zero and two, carry one and minus one: sum zero. Every entry comes out zero. So A x is the zero vector, which is zero times x. Eigenvalue zero. And zero, one, zero, minus one works the same way, also with eigenvalue zero.

17. So the four-cycle has eigenvalues two, zero, zero, and minus two. Four eigenvalues for a four-by-four matrix, and that is a general fact: an N by N symmetric matrix has exactly N eigenvalues, counted with repetition, and they are all real numbers. We will not prove that, but we will use it constantly. The list of eigenvalues is called the spectrum of the matrix, or of the graph.

## E02S05 — A two-by-two example, solved completely

18. For a two-by-two matrix you can find the eigenvalues by hand, and we will need this skill in episode five. Take the matrix with rows two, one and one, two. We want a number lambda and a vector x, y, not both zero, with A times x, y equal to lambda times x, y.

19. Write out the two equations: two x plus y equals lambda x, and x plus two y equals lambda y. Move everything to one side: two minus lambda times x plus y equals zero, and x plus two minus lambda times y equals zero. Two equations, two unknowns x and y. Normally the only solution is x equals y equals zero. A nonzero solution exists only when the equations are dependent, which happens exactly when two minus lambda, squared, minus one times one, is zero.

20. That quantity, two minus lambda squared minus one, is the determinant of the matrix with lambda subtracted from the diagonal. For any two-by-two matrix with rows p, q and r, s, the determinant is p s minus q r, and the eigenvalues are the solutions of p minus lambda times s minus lambda, minus q r, equals zero. That is a quadratic equation in lambda, so there are two eigenvalues.

21. Solve ours. Two minus lambda squared equals one, so two minus lambda is plus or minus one, so lambda is one or three. For lambda equals three: the first equation says minus x plus y equals zero, so x equals y. Eigenvector one, one. Check: two plus one is three, one plus two is three. Three times one, one. For lambda equals one: x plus y equals zero, eigenvector one, minus one. Check: two minus one is one, one minus two is minus one. One times one, minus one.

22. A shortcut you will see used later. For a two-by-two matrix, the two eigenvalues add up to the trace, the sum of the diagonal entries, and multiply to the determinant. Here: three plus one is four, which is two plus two. Three times one is three, which is two times two minus one times one. So if you know the trace and determinant, the eigenvalues are the two roots of lambda squared minus trace times lambda plus determinant equals zero.

## E02S06 — Why every cubic graph has eigenvalue three

23. Back to graphs. Take any cubic graph and the all-ones vector, one at every vertex. Multiplying by A sums the neighbours, and every vertex has three neighbours each carrying one. So A times the all-ones vector is three times the all-ones vector. Three is always an eigenvalue of a cubic graph, with the all-ones vector as eigenvector. In general, a d-regular graph has eigenvalue d.

24. And three is the largest eigenvalue. Here is why. Suppose x is an eigenvector with eigenvalue lambda, and let vertex m be where x is largest in absolute value. The entry of A x at m is the sum of three neighbours, each at most x m in absolute value, so A x at m is at most three times the absolute value of x m. But A x at m is lambda times x m. So the absolute value of lambda is at most three. Every eigenvalue of a cubic graph lies between minus three and three.

## E02S07 — The spectrum of the Petersen graph

25. The Petersen graph has ten vertices, so ten eigenvalues. Here they are: three, once. One, five times. Minus two, four times. Mathematicians write this as three to the one, one to the five, minus two to the four, where the exponent means how many times the eigenvalue appears, its multiplicity. One plus five plus four is ten.

26. We will not find all ten by hand now, but we can verify one. Here is a vector: one at u three, one at u four, minus one at v zero, minus one at v two, and zero at the other six vertices. Check vertex u three: its neighbours are u two, u four, and v three, carrying zero, one, and zero. Sum one, and the vector has one at u three. Check v zero: neighbours v two, v three, and u zero, carrying minus one, zero, zero. Sum minus one, matching. Check a vertex where the vector is zero, say u zero: neighbours u one, u four, v zero carry zero, one, minus one. Sum zero, matching. Do the remaining seven vertices yourself; every one works. So this is an eigenvector with eigenvalue one. In episode five we will see a method that produces the whole list from five two-by-two matrices, each as easy as the example we just solved: three and one from one of them, one and minus two from each of the other four. That is where the five, and the four, come from.

27. For now, the thing to notice is the gap. The largest eigenvalue is three. The next largest is one. There is nothing in between. That gap, three minus one equals two, is called the spectral gap, and the next episode is about why it measures how well connected the graph is.

## E02S08 — The kernel and the nullity

28. One more definition, because the second half of this series lives on it. The eigenvalue zero is special. An eigenvector with eigenvalue zero satisfies A x equals zero: the matrix sends it to the zero vector. The set of all vectors with A x equals zero is called the kernel, or null space, of A. It always contains the zero vector, and the question is whether it contains anything else.

29. For the four-cycle we found two independent kernel vectors: one, zero, minus one, zero, and zero, one, zero, minus one. Any combination of them, like two times the first plus three times the second, is also in the kernel: two, three, minus two, minus three. Check vertex zero: neighbours one and three carry three and minus three, sum zero. The kernel is a two-dimensional space, and we say the nullity of A is two.

30. Nullity means: how many independent directions are there in which A sends things to zero. Equivalently, how many times zero appears as an eigenvalue. For the four-cycle it is two. For the Petersen graph, zero does not appear among three, one, and minus two, so the nullity is zero. Remember the word. Episodes nine onward ask how large the nullity can be made.

## E02S09 — Recap

31. What you should now be able to do. Write the adjacency matrix of a small graph. Multiply it by a vector, and explain the result as summing over neighbours. State what an eigenvector and eigenvalue are, and verify a claimed one by hand. Find the eigenvalues of a two-by-two matrix using the trace and determinant. Explain why three is the largest eigenvalue of a cubic graph. And define kernel and nullity.

32. Next episode: what do eigenvalues actually tell you? We will send a random walker around the Petersen graph, watch how fast it forgets where it started, and see that the speed is set by the second-largest eigenvalue. Then we meet the magic number two root two.
